DESIGN MAF GAME - bases (bleu ciel / rose pur)
===============================================

UTILISATION (PowerShell, depuis la racine du projet) :

  cd C:\Users\hp\Documents\999\maf-game
  powershell -ExecutionPolicy Bypass -File .\design-setup\lancer-tout.ps1

(Mets le dossier "design-setup" de ce zip dans ton projet, ou change le chemin.)
Tu peux aussi lancer les scripts 01 a 04 un par un, dans l'ordre.

CE QUI EST CREE
  src/styles/tokens.css       les 2 themes (couleurs, rayons, flou) -> data-theme="ciel" ou "rose"
  src/styles/base.css         fond, texte, focus, titres .title-tech
  src/styles/components.css   .btn .btn--primary .btn-cta .card--hero .chip .tab .size .field .price ...
  src/styles/bridge.css       applique le look a tes cartes/boutons actuels (supprime-le pour annuler)
  src/styles/index.css        point d'entree
  src/theme/useTheme.js       hook : { theme, setTheme, toggle } (memorise dans localStorage)
  src/components/ThemeToggle.jsx   2 pastilles ciel / rose

Le script 04 modifie main.jsx, index.html et App.jsx (copies .bak creees).
Si un repere n'est pas trouve, ajoute a la main :
  main.jsx  -> apres "import App from './App.jsx'" :  import './styles/index.css'
  App.jsx   -> import ThemeToggle from "./components/ThemeToggle";   et   <ThemeToggle /> dans le <header>
